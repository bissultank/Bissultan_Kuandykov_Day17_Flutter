# Counter App с SharedPreferences

Приложение-счётчик, которое сохраняет своё значение между запусками с использованием SharedPreferences.

## 📋 Структура проекта

```
counter_app/
├── lib/
│   ├── main.dart           # Точка входа в приложение
│   ├── counter_page.dart   # UI страницы со счётчиком
│   └── counter_model.dart  # Модель с логикой и SharedPreferences
└── pubspec.yaml            # Зависимости проекта
```

## 🎯 Что реализовано

### 1. **CounterModel** (counter_model.dart)
Класс с бизнес-логикой:
- `int counter` - хранит текущее значение
- `loadCounter()` - загружает значение из SharedPreferences
- `saveCounter()` - сохраняет значение в SharedPreferences
- `increment()` - увеличивает на 1 и автоматически сохраняет

### 2. **CounterPage** (counter_page.dart)
StatefulWidget с UI:
- Загружает счётчик в `initState()`
- Отображает индикатор загрузки
- Показывает текущее значение счётчика
- Кнопка для увеличения значения
- Обновляет UI через `setState()`

### 3. **Ключевые особенности**
✅ Асинхронная загрузка данных при старте
✅ Автоматическое сохранение при каждом изменении
✅ Индикатор загрузки во время чтения данных
✅ Разделение логики (модель) и UI (виджет)
✅ Значение сохраняется между перезапусками

## 📱 Как это работает

### Жизненный цикл данных:

```
1. Запуск приложения
   ↓
2. initState() → loadCounter()
   ↓
3. Чтение из SharedPreferences
   ↓
4. setState() → UI обновляется
   ↓
5. Пользователь нажимает кнопку
   ↓
6. increment() → counter++ → saveCounter()
   ↓
7. Запись в SharedPreferences
   ↓
8. setState() → UI обновляется
```

## 🔑 Ключевые концепции

### SharedPreferences
```dart
// Сохранение
final prefs = await SharedPreferences.getInstance();
await prefs.setInt('counter', counter);

// Чтение
counter = prefs.getInt('counter') ?? 0; // 0 - значение по умолчанию
```

### Асинхронность
```dart
Future<void> loadCounter() async {
  // await ждёт завершения операции
  await counterModel.loadCounter();
  // Только потом обновляем UI
  setState(() {});
}
```

### Разделение ответственности
- **CounterModel** = логика + данные
- **CounterPage** = UI + взаимодействие
- **main.dart** = запуск приложения
